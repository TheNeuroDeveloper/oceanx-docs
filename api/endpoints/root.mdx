<Info>
  **`GET /api/v1`** · Unauthenticated
</Info>

Returns the API description, endpoint discovery and a link to these docs. Useful
as a health/version check. The discovery response advertises the read-only
[`POST /route`](/api/endpoints/router#request-a-route) quote endpoint; route
discovery does not grant build, signing or submission authority.

## Request

```bash
curl https://www.oceanx.trade/api/v1
```

No authentication is required for this endpoint.
