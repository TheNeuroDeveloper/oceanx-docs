<Info>
  **`GET /api/v1/callouts/feed`** · **`GET /api/v1/callouts/token/{mint}`**
</Info>

Callouts are public token calls posted by OceanX users. Each callout tracks the
clicks, distinct traders and USD volume it drove, and the creator earns a share
of platform fees on that attributed volume. These endpoints are read-only.

Both require the **`md.read`** scope (on every key by default) and use the
standard [REST budget](/api/rate-limits).

## Global feed

`GET /api/v1/callouts/feed`

| Query | Default | Notes |
| --- | --- | --- |
| `sort` | `recent` | `recent` (newest first) or `top` (by attributed volume). |
| `limit` | `20` | 1–50. |
| `cursor` | — | Opaque cursor from the previous page's `nextCursor`. |

```bash
curl "https://www.oceanx.trade/api/v1/callouts/feed?sort=top&limit=10" \
  -H "Authorization: Bearer $OCEANX_API_KEY"
```

## Callouts for one token

`GET /api/v1/callouts/token/{mint}`

| Path / query | Default | Notes |
| --- | --- | --- |
| `mint` | — | **Required.** Base58 Solana mint address. |
| `sort` | `top` | `top` or `recent`. |
| `limit` | `20` | 1–50. |
| `cursor` | — | Opaque pagination cursor. |

```bash
curl "https://www.oceanx.trade/api/v1/callouts/token/DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263" \
  -H "Authorization: Bearer $OCEANX_API_KEY"
```

## Response

Both endpoints return a `CalloutPage`:

```json
{
  "callouts": [
    {
      "id": "ftVBe48_Q8",
      "mint": "DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263",
      "body": "Dog coin classic — volume rotating back in.",
      "tokenSymbol": "Bonk",
      "tokenName": "Bonk",
      "tokenImageUrl": "https://…",
      "priceUsdAtCreate": 0.0000023,
      "status": "active",
      "clickCount": 41,
      "traderCount": 12,
      "attributedVolumeUsd": 18250.4,
      "earnedUsd": 18.25,
      "pointsAwarded": 1825,
      "createdAt": "2026-08-13T18:10:45.359Z",
      "expiresAt": "2026-08-20T18:10:45.359Z",
      "creator": {
        "id": "…",
        "username": "adamx",
        "displayName": "AdamX",
        "avatarUrl": "https://…"
      }
    }
  ],
  "nextCursor": null
}
```

Field notes:

| Counter | Meaning |
| --- | --- |
| `agree_count` | Agree votes on the callout. |
| `disagree_count` | Disagree votes on the callout. |
| `clickCount` | Callout clicks. |
| `traderCount` | Distinct attributed traders. |
| `pointsAwarded` | Points awarded from attributed trades. |

These counters are exact nonnegative JSON integers from `0` through
`9007199254740991`. If a selected callout has a counter outside that range,
both endpoints keep their best-effort response: HTTP 200 with
`{ "callouts": [], "nextCursor": null }`. They do not return rounded counts or
a partial page. This fallback applies to selected rows, not the next-page
lookahead.

`priceUsdAtCreate`, `attributedVolumeUsd` and `earnedUsd` are finite JSON
numbers. An unresolved price remains `null`. A non-finite metric, or a nonzero
metric that would become zero when converted to a JSON number, uses the same
empty-page fallback. Existing finite values and stored amounts are unchanged.

Both lists share a two-second read budget across schema access, database pool
and lock waits, row conversion and cursor encoding. An exhausted budget cancels
the read and returns HTTP 200 with `{ "callouts": [], "nextCursor": null }`.
Later requests can recover normally; this fallback does not prove the feed is
empty.

- `priceUsdAtCreate` is the server-resolved token price when the callout was
  posted — the baseline for "% since callout". `null` when no price resolved.
- `attributedVolumeUsd` / `earnedUsd` / `pointsAwarded` update as attributed
  trades settle; `traderCount` counts distinct traders.
- The public share page for any callout is `https://www.oceanx.trade/c/{id}`.
- Creating callouts is app-only for now (token page → megaphone); the API
  surface is read-only.
- Both lists return active, unexpired callouts. Removed callouts are excluded,
  including retained removal markers, in both `recent` and `top` order.
